# ⚙️ Nivesha Backend

### 🚀 Powering the Stock Trading Platform

This is the backend service for **Nivesha**, a full-stack stock trading platform.
It handles all core functionalities including data management, order processing, and API communication with the frontend and dashboard.

---

🌐 **Live API**
https://nivesha-stock-trading-platform-backend-1.onrender.com

---

## ✨ What It Handles

* 📦 Manages stock holdings and positions
* 🛒 Processes buy and sell orders
* 🔄 Serves REST APIs for frontend & dashboard
* 📊 Stores and retrieves data from database
* ⚡ Ensures smooth data flow across the app

---

## 🧠 Architecture

The backend is built using a RESTful architecture:

* Express server handles API routes
* MongoDB stores application data
* API endpoints serve frontend requests
* Modular structure for scalability

---

## 🛠️ Tech Stack

Node.js • Express.js • MongoDB • Mongoose

---

## 📡 API Endpoints

| Method | Endpoint        | Description         |
| ------ | --------------- | ------------------- |
| GET    | `/allHoldings`  | Fetch all holdings  |
| GET    | `/allPositions` | Fetch all positions |
| POST   | `/newOrder`     | Create new order    |


* 🌐 Main App
* 📊 Dashboard

Both consume this backend API for data.
